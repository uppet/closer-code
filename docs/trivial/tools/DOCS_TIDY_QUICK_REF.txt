┌─ 快速开始 ──────────────────────────────────────────────────┐
│                                                              │
│  1. 启动 Closer Code                                        │
│     $ node src/closer-cli.jsx                               │
│                                                              │
│  2. 加载技能                                                 │
│     你: 请加载 docs-tidy 技能                                │
│                                                              │
│  3. 使用技能                                                 │
│     你: 请分析 docs 目录下的文档                             │
│                                                              │
│  4. 查看报告                                                 │
│     $ cat docs_tidy_report.md                               │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌─ 常用命令 ──────────────────────────────────────────────────┐
│                                                              │
│  • 基本分析                                                 │
│    "请使用 docs-tidy 技能分析 docs 目录"                    │
│                                                              │
│  • 指定输出文件                                             │
│    "分析 docs 目录，输出到 cleanup_report.md"               │
│                                                              │
│  • 严格模式                                                 │
│    "用严格模式分析 src/docs"                                │
│                                                              │
│  • 宽松模式                                                 │
│    "用宽松模式分析文档"                                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌─ 报告分类 ──────────────────────────────────────────────────┐
│                                                              │
│  ✅ KEEP        - 保留，重要且活跃维护                       │
│  ⚠️  REVIEW      - 需要人工审查                               │
│  🔀 MERGE       - 建议合并                                   │
│  ⚠️  DEPRECATE   - 标记过时，保留作参考                       │
│  ❌ DELETE      - 可以安全删除                               │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌─ 分析标准 ──────────────────────────────────────────────────┐
│                                                              │
│  多余程度：                                                  │
│    • 高度多余  - 90%+ 相似度                                │
│    • 中度多余  - 70-90% 相似度                              │
│    • 轻度多余  - 50-70% 相似度                              │
│                                                              │
│  过时程度：                                                  │
│    • 严重过时  - >2 年未更新                                │
│    • 中度过时  - 1-2 年未更新                               │
│    • 轻度过时  - <1 年未更新                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌─ 参数说明 ──────────────────────────────────────────────────┐
│                                                              │
│  directory   - 目录路径（默认：docs）                        │
│  outputFile  - 报告文件名（默认：docs_tidy_report.md）       │
│  severity    - 严格程度（low/medium/high）                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌─ 最佳实践 ──────────────────────────────────────────────────┐
│                                                              │
│  ✓ 分析前备份文档                                           │
│  ✓ 先用 medium 模式                                         │
│  ✓ 仔细阅读报告                                             │
│  ✓ 不要立即删除                                             │
│  ✓ 使用版本控制                                             │
│  ✓ 征求团队意见                                             │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌─ 故障排除 ──────────────────────────────────────────────────┐

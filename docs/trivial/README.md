# Trivial 文档目录

本目录包含项目中过时或过于基础/小儿科功能的文档。

## 📂 目录结构

### 🎭 演示与教学
- `demos/` - 演示脚本和教学材料
- `examples/` - 基础示例代码

### 🧪 实验性功能
- `experiments/` - 实验性功能和测试代码

### 📚 基础教程
- `tutorials/` - 过于基础或过时的教程

### 🎯 工具脚本
- `tools/` - 小工具和脚本

### 📝 临时文档
- `temp/` - 临时性和实验性文档

## ⚠️ 说明

这些文档被移动到这里是因为：
1. 功能过于基础，不适合主文档
2. 已经过时或被新功能替代
3. 属于实验性或临时性内容
4. 重复或冗余的文档

保留这些文档是为了：
- 历史参考
- 教学目的
- 可能的未来恢复

## 🔄 清理原则

定期清理此目录：
- 删除完全无用的文档
- 合并重复内容
- 更新过时的参考信息

# 实施计划：改进交互式配置向导

## 📋 任务概述

根据 `ds_improve_tips.md` 中的建议 A2，改进交互式配置向导，降低新手使用门槛。

**目标**：改进 `src/setup.js` 和 `src/commands/setup.js`，提供更友好的配置体验。

**优先级**：⭐⭐⭐⭐⭐（高优先级）
**工作量**：中（3-5 天）
**影响范围**：新用户

---

## 🔍 当前状态分析

### 现有配置系统
- **位置**: `src/setup.js` - 主配置脚本
- **位置**: `src/commands/setup.js` - 命令桥接
- **功能**: 基本的交互式配置
- **问题**: 不够友好，选项太多容易混淆

### 现有功能
1. 选择 AI 提供商（Anthropic, OpenAI, Ollama）
2. 输入 API Key
3. 设置工作目录
4. 保存配置到 `~/.closer-code/config.json`

### 需要改进的地方
1. **新手友好性**: 提供更详细的指导
2. **API Key 获取帮助**: 提供获取链接和说明
3. **配置选项简化**: 提供"快速配置"和"高级配置"选项
4. **配置验证**: 验证 API Key 和工作目录
5. **配置摘要**: 显示配置摘要和常用命令提示

## 🎯 实施方案

### 1. 改进配置流程
- **快速配置**: 默认选项，最少输入
- **高级配置**: 自定义所有选项
- **配置验证**: 验证 API Key 有效性（可选）
- **配置摘要**: 显示最终配置

### 2. 添加帮助信息
- **API Key 获取链接**: 提供官方链接
- **模型说明**: 解释不同模型的区别
- **环境变量说明**: 如何安全存储 API Key

### 3. 改进用户体验
- **进度指示**: 显示配置进度
- **错误处理**: 友好的错误提示
- **配置预览**: 显示将要保存的配置

### 4. 添加配置命令
- `/config` 命令：查看和修改配置
- 配置热重载：无需重启

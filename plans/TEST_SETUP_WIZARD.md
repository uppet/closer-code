# 快速测试指南：改进的配置向导

## 🎯 测试目标

验证改进的配置向导和配置管理命令是否正常工作。

## 📋 测试步骤

### 1. 备份现有配置（可选）

```bash
# 备份现有配置
cp ~/.closer-code/config.json ~/.closer-code/config.json.backup
```

### 2. 测试增强版配置向导

```bash
# 方式 1: 使用 npm 脚本
npm run build:main
node src/setup-enhanced.js

# 方式 2: 通过 setup 命令（默认使用增强版）
npm run build
node dist/index.js setup
```

### 3. 测试配置向导流程

启动配置向导后，验证以下步骤：

1. **欢迎消息** - 显示 Closer Code 介绍
2. **配置模式选择** - 快速配置 vs 高级配置
3. **AI 提供商选择** - 显示详细说明
4. **API Key 输入** - 提供获取链接和说明
5. **模型选择** - 显示模型说明
6. **工作目录设置** - 默认使用当前目录
7. **配置摘要** - 显示配置预览
8. **配置确认** - 确认保存
9. **使用提示** - 显示后续操作指南

### 4. 测试 /config 命令

启动 Cloco 后，输入：
```
/config
```

验证输出包含：
- AI 配置信息（提供商、模型、Token 限制）
- 行为配置（工作目录、自动计划等）
- 工具配置（启用工具数量）
- UI 配置（主题、行号等）
- 配置文件路径

### 5. 测试 /help 命令

输入：
```
/help
```

验证 `/config` 命令是否出现在帮助列表中。

### 6. 测试配置热重载（可选）

1. 修改配置文件 `~/.closer-code/config.json`
2. 在 Cloco 中重新加载配置
3. 验证配置变更生效

## ✅ 验证标准

### 配置向导
- [ ] 欢迎消息清晰友好
- [ ] 配置模式选择正常工作
- [ ] AI 提供商选择显示详细说明
- [ ] API Key 输入提供获取链接
- [ ] 模型选择显示说明信息
- [ ] 配置摘要显示正确信息
- [ ] 配置保存成功
- [ ] 使用提示显示完整

### /config 命令
- [ ] 命令能正常执行
- [ ] 显示完整的配置信息
- [ ] 配置信息准确无误
- [ ] 配置文件路径显示正确

### /help 命令
- [ ] `/config` 命令出现在帮助列表中
- [ ] 帮助信息完整准确

### 向后兼容性
- [ ] 现有配置能正常加载
- [ ] 原版配置向导仍可用（通过 `--legacy` 参数）
- [ ] 配置文件格式兼容

# Dispatch Agent Batch 模式验证场景

> **日期**: 2026-01-27
> **目标**: 验证 dispatch_agent 在 batch 模式下的实际运行效果

## 📋 场景设计

### 场景 1: 代码搜索任务

**用户请求**:
```
搜索项目中所有与 "config" 相关的文件，找出配置文件的路径和主要内容
```

**预期行为**:
1. 主 AI 识别这是一个搜索任务
2. 调用 dispatch_agent 工具
3. Agent 执行以下操作：
   - 使用 searchFiles 搜索包含 "config" 的文件
   - 使用 searchCode 搜索配置相关的代码
   - 使用 readFile 读取关键配置文件
   - 返回结构化的搜索结果
4. 主 AI 总结结果并展示给用户

### 场景 2: 多关键词并发搜索

**用户请求**:
```
同时搜索项目中的 "logger"、"error"、"handler" 关键词，找出它们的使用位置
```

**预期行为**:
1. 主 AI 识别需要搜索多个关键词
2. 并发启动 3 个 agents
3. 每个 agent 独立搜索一个关键词
4. 汇总所有 agent 的结果
5. 展示综合报告

### 场景 3: 文件结构探索

**用户请求**:
```
探索 src/agents 目录的结构，列出所有文件和它们的主要功能
```

**预期行为**:
1. Agent 使用 listFiles 列出目录
2. 使用 readFile 读取每个文件的头部注释
3. 提取文件功能描述
4. 返回结构化的目录报告

## 🔧 Batch 命令

### 命令 1: 基础搜索测试
```bash
closer-batch "搜索项目中所有与 'config' 相关的文件，找出配置文件的路径和主要内容"
```

### 命令 2: 并发搜索测试
```bash
closer-batch "同时搜索项目中的 'logger'、'error'、'handler' 关键词，找出它们的使用位置"
```

### 命令 3: 目录探索测试
```bash
closer-batch "探索 src/agents 目录的结构，列出所有文件和它们的主要功能"
```

### 命令 4: Agent 状态查询
```bash
closer-batch "/agents"
```

## ✅ 验收标准

- [ ] Agent 成功启动并执行任务
- [ ] Agent 只使用只读工具（不修改文件）
- [ ] Agent 返回结构化的搜索结果
- [ ] 主 AI 正确总结 agent 结果
- [ ] 并发 agents 正常工作
- [ ] /agents 命令显示正确的状态信息
- [ ] 缓存机制正常工作（重复任务使用缓存）
- [ ] 性能可接受（单个 agent < 30秒）

## 📊 测试执行计划

1. **环境准备**
   - 设置 API key（如果需要）
   - 确认项目已构建

2. **执行测试**
   - 运行命令 1（基础搜索）
   - 运行命令 2（并发搜索）
   - 运行命令 3（目录探索）
   - 运行命令 4（状态查询）

3. **结果验证**
   - 检查输出格式
   - 验证工具调用
   - 确认结果正确性
   - 测量执行时间
